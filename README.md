## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or later)
- npm
- MongoDB or MySQL (if the experiment uses a database)

### Installation

```bash
# Clone the repository
git clone https://github.com/cu24250214-dotcom/Full_stack_BTCS303P.git

# Go into the project folder
cd Full_stack_BTCS303P

# Go into a specific experiment and install dependencies
cd Experiment-1
npm install

# Run the app
npm start
```
